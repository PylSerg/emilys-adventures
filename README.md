# Emily’s Adventures 🌲✨

**Розділ 1: Таємниця зоряного лісу**. Ізометрична браузерна RPG на Three.js.

## Структура проєкту

```text
emilys-adventures/
├── index.html                  # HTML-розмітка та підключення ресурсів
├── src/
│   ├── main.js                 # Three.js, анімації, керування, квести
│   └── styles.css              # Стилі інтерфейсу й адаптивний дизайн
├── assets/
│   └── hero/
│       ├── emily-atlas.png     # 4 × 4 анімаційні кадри Емілі
│       ├── emily-portrait.png  # Портрет для головного екрана
│       ├── персонаж.svg        # Оригінальний спрайт
│       └── [16 файлів напрямків].svg # Оригінальні анімації
└── README.md
```

SVG-файли у `assets/hero/` не змінені. Атлас зібрано з їхніх вбудованих піксельних зображень; для відображення гри використовуються лише два PNG з цієї папки, а SVG збережені як вихідні ресурси для подальших змін.

## Запуск

Відкрий **`index.html`** у браузері. Потрібен інтернет для Three.js з CDN. Якщо Chrome/ChromeOS обмежує запуск через `file://`, запусти локальний сервер у корені проєкту:

```bash
python3 -m http.server 8000
```

і відкрий `http://localhost:8000/`.

Завантаження на Netlify: публікуй **усю папку проєкту** (а не лише `index.html`), щоб ресурси `src/` та `assets/` залишилися доступними. Перегляд файлів безпосередньо в інтерфейсі Google Drive не є вебхостингом.

## Керування

- `WASD` / стрілки: рух;
- `E`: взаємодія;
- `Пробіл`: атака;
- `Q`: зілля (+40 HP);
- `I`: рюкзак;
- `Esc`: пауза;
- На смартфонах: аналоговий віртуальний джойстик і 4 круглі кнопки дій. Положення залежить від вибраної схеми керування (див. v1.4 нижче).
- Торкання місцевості теж залишено: можна просто вказати, куди йти.

## Мета

Поговорити з Мірою, відшукати три зоряні кристали та віднести їх до вівтаря. Тіньові духи атакуватимуть Емілі, тож бережи здоров'я. Гра автоматично зберігає прогрес у `localStorage` браузера. Ключ збереження не змінився при рефакторингу.

## Оптимізація (v1.1)

- При анімації спрайта змінюються лише `texture.offset`, **без `texture.needsUpdate = true`**. Це усуває зайві повторні завантаження текстури на GPU.
- Обмежено device pixel ratio рендерингу: 1.25 на десктопах, 1.15 на мобільних.
- Розмір карти тіней знижено з 2048² до 1024².
- Квіти та камінці об'єднано в `THREE.InstancedMesh` для зменшення кількості викликів промальовування.
- Сцена, діалоги, квест та налаштування збереження не змінені.

Three.js версії `0.163.0` завантажується з `jsDelivr`.


## Графіка й телефони (v1.2)

- У верхній панелі кнопка **⚙️** відкриває налаштування графіки. Доступна до початку гри та під час проходження.
- Профілі **Економний**, **Збалансований** і **Високий**. Будь-яке ручне редагування переводить профіль у режим **Власний**.
- Окремо налаштовуються **роздільність 3D (60–150% від CSS-пікселів)**, **тіні** (вимкнені/512/1024/2048), **максимальний FPS** (30/45/60/без обмеження), **детальність декорацій**, **розмиття інтерфейсу** та **лічильник FPS**.
- На сенсорних пристроях за замовчуванням обрано економний профіль. Параметри зберігаються у `localStorage` ключем `emilys-adventures-graphics-v2`, окремо від проходження гри.
- Портретна і ландшафтна орієнтації: адаптивна камера, компактні кнопки **📜** і **🗺️** для панелей квесту й мінімапи, великі сенсорні напрямки зліва й кнопки дій справа. Торкання землі також переміщує Емілі.
- Зміни графіки застосовуються без перезавантаження. Перевірити швидкість можна вбудованим лічильником FPS (це FPS промальовування, не повноцінний GPU-профайлер).


## Мобільне керування (v1.4)

Відкрий **⚙️ Налаштування графіки → Мобільне керування** та обери схему:

- **📱 Автоматично** (за замовчуванням): **Центр + дуга** у портретній орієнтації, **Два великі пальці** в альбомній. Режим змінюється одразу при повороті екрана.
- **🎯 Центр + дуга**: джойстик знизу по центру та чотири круглі кнопки півколом над ним.
- **👐 Два великі пальці**: джойстик ліворуч, чотири кнопки праворуч. Зручно рухатися й атакувати двома пальцями одночасно.
- **🕹️ Вільний джойстик**: торкнися вільної нижньої лівої зони екрана, щоб джойстик з'явився під пальцем. Кнопки дій праворуч. Кнопкою **«Пересунути»** в налаштуваннях можна ввімкнути режим перетягування всього блоку кнопок; **«Готово»** фіксує позицію, **«Скинути»** повертає стандартну.

Джойстик підтримує **360° рух**, невелику мертву зону й змінну швидкість залежно від відхилення. Для керування використовуються `Pointer Events` із `setPointerCapture`, щоб одночасно тримати джойстик та натискати дії. Після відпускання пальця рукоятка повертається до центру. Зберігаються і обраний режим, і налаштування позиції кнопок у `localStorage` (`emilys-adventures-controls-v1`), окремо від графіки та ігрового прогресу. Клавіатура та керування натисканням на місцевість залишилися.

**Перевірка v1.4:** синтаксис JavaScript, верстка в портретному режимі 390×844 / 320×640 і горизонтальному 844×390, перемикання схем при повороті, обробка руху й відпускання джойстика, перетягування кнопок, повернення до автоматичної схеми та мультитач-тест у Chromium (рух джойстиком і атака другим пальцем одночасно). Перевірка у реальному WebGL-браузері на телефоні лишається за гравцем.
