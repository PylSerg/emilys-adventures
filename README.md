# Emily’s Adventures 🌲✨

**Розділ 1: Таємниця зоряного лісу**. Ізометрична браузерна RPG на Three.js.

## Структура проєкту

```text
emilys-adventures/
├── index.html                  # HTML-розмітка та підключення ресурсів
├── src/
│   ├── main.js                 # Three.js, анімації, керування, квести
│   └── styles.css              # Стилі інтерфейсу й адаптивний дизайн
├── assets/
│   └── hero/
│       ├── emily-atlas.png     # 4 × 4 анімаційні кадри Емілі
│       ├── emily-portrait.png  # Портрет для головного екрана
│       ├── персонаж.svg        # Оригінальний спрайт
│       └── [16 файлів напрямків].svg # Оригінальні анімації
└── README.md
```

SVG-файли у `assets/hero/` не змінені. Атлас зібрано з їхніх вбудованих піксельних зображень; для відображення гри використовуються лише два PNG з цієї папки, а SVG збережені як вихідні ресурси для подальших змін.

## Запуск

Відкрий **`index.html`** у браузері. Потрібен інтернет для Three.js з CDN. Якщо Chrome/ChromeOS обмежує запуск через `file://`, запусти локальний сервер у корені проєкту:

```bash
python3 -m http.server 8000
```

і відкрий `http://localhost:8000/`.

Завантаження на Netlify: публікуй **усю папку проєкту** (а не лише `index.html`), щоб ресурси `src/` та `assets/` залишилися доступними. Перегляд файлів безпосередньо в інтерфейсі Google Drive не є вебхостингом.

## Керування

- `WASD` / стрілки: рух;
- `E`: взаємодія;
- `Пробіл`: атака;
- `Q`: зілля (+40 HP);
- `I`: рюкзак;
- `Esc`: пауза;
- На смартфонах: сенсорні кнопки й торкання місцевості.

## Мета

Поговорити з Мірою, відшукати три зоряні кристали та віднести їх до вівтаря. Тіньові духи атакуватимуть Емілі, тож бережи здоров'я. Гра автоматично зберігає прогрес у `localStorage` браузера. Ключ збереження не змінився при рефакторингу.

## Оптимізація (v1.1)

- При анімації спрайта змінюються лише `texture.offset`, **без `texture.needsUpdate = true`**. Це усуває зайві повторні завантаження текстури на GPU.
- Обмежено device pixel ratio рендерингу: 1.25 на десктопах, 1.15 на мобільних.
- Розмір карти тіней знижено з 2048² до 1024².
- Квіти та камінці об'єднано в `THREE.InstancedMesh` для зменшення кількості викликів промальовування.
- Сцена, діалоги, квест та налаштування збереження не змінені.

Three.js версії `0.163.0` завантажується з `jsDelivr`.
